📄 Resume Project
A simple and elegant Resume Web Application built with Django/HTML/CSS. This project allows users to showcase their professional experience, skills, education, and projects in a clean, responsive layout.

🚀 Features
✅ Professional and clean resume layout

✅ Responsive design for mobile and desktop

✅ Sections for Skills, Experience, Education, Projects, and Contact

✅ Easy to customize and update content

🛠️ Tech Stack
Backend: Django

Frontend: HTML, CSS, Bootstrap

Database: SQLite
